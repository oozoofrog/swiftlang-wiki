# Swift.org Documentation 허브 해설

다운로드 번들에 포함된 공식/준공식 문서를 위키 관점으로 다시 정리한 페이지다.

- 원문 유형: `html`
- 다운로드 번들 경로: `swift.org/documentation/index.html`
- 원본 URL: https://www.swift.org/documentation/

## 이 문서는 무엇을 설명하나

Swift.org 문서 전체의 정보 구조를 보여 주는 최상위 허브다. 언어 문서, 기사, 기여 문서가 어디에 놓여 있는지 한 번에 파악할 수 있다.

## 핵심 포인트

- TSPL, API Design Guidelines, Standard Library, Core Libraries, Package Manager, REPL/Debugger가 한 축으로 묶여 있다.
- Articles 영역은 value/reference, concurrency, C++ interop, SDK 가이드처럼 실용 주제를 모은다.
- Contributing 영역은 source code, CI, compiler architecture 같은 개발자 문서로 이어진다.
- 독립 기술 문서라기보다 “공식 문서 지형도” 역할을 한다.

## 컴파일러와 어떻게 연결되나

- swift-compiler-architecture와 source code 문서로 연결
- continuous-integration와 개발자 문서 묶음
- SwiftPM / REPL / C++ interop 같은 도구·언어 경계 문서의 인덱스

## 언어 표면에서 어떻게 들어오면 좋은가

- TSPL과 API 디자인 가이드
- 표준 라이브러리와 코어 라이브러리
- value/reference, concurrency, interop
