# swift-format

Swift 소스 코드 포매팅 및 린팅 도구. [[swift-syntax-package|SwiftSyntax]] 기반.

## 기능

- **포매팅**: `swift-format format` — 코드 스타일 자동 적용
- **린팅**: `swift-format lint` — 스타일 위반 검출
- 구성 파일(`.swift-format`)로 규칙 커스터마이즈
