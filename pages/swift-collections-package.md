# Swift Collections

표준 라이브러리를 보완하는 데이터 구조 패키지.

## 주요 타입

- **Deque**: 양방향 큐 (O(1) 앞/뒤 삽입/삭제)
- **OrderedSet**: 순서 유지 집합
- **OrderedDictionary**: 순서 유지 사전
- **TreeSet / TreeDictionary**: B-Tree 기반 정렬 컬렉션
- **Heap**: 최소/최대 힙
- **BitSet / BitArray**: 비트 수준 컬렉션
